# Diff 2.1.32 vs 2.2.x (читать только при расхождении с докой)

Эталон — **2.1.32 beta (24.02.2021)**. Дока `serpent.vtt.fi/docs` и `SERPENT_KNOWLEDGE.md`
описывают 2.2.3–2.2.5. Ниже только то, что бьёт по HW-набору.

| Тема | 2.1.32 (наше) | 2.2.x (дока) |
|---|---|---|
| CLI | только одинарный дефис: `-version -norun -noplot -omp -plot` | с 2.2.2 принимают и `-`, и `--` |
| `sss2 INPUT` | `INPUT` = базовое имя без расширения | то же, но доки упоминают `.serp/.txt` авто-подстановку |
| `sg` источник | `src NAME n\|p sg DMAT MODE` + `sp/srad/sm` (как в HW) | тот же синтаксис; в 2.2 больше диагностики `emission rate` |
| `sb` спектры | как в HW (`sb NE INTT ...` строки до следующей карты) | то же |
| `ene 4 scale44` | встроенные структуры есть; в `de` напрямую нельзя — только через `ene` | то же правило, список структур шире |
| `dr -11/-200/-100` | `-11` спектр, `-200` доза (по эталонам), `-100+fun` | та же семантика; в 2.2 больше спец-ответов Kerry |
| `tme/di`, `wwgen/wwin` | как в HW4/HW5 | то же |
| `set TMS/DBRC/URES` тонкости | дефолты 2.1.32, не трогать без нужды | в 2.2 менялись дефолты/диапазоны — сверяться с докой |
| `plot/gplot/mplot` | legacy `plot/mesh`, картинка `_geom*.png` (см. HW6 `_geom1.png`) | `gplot/mplot` modern с 2.2.2 |

Правило: при споре «дока говорит X, а 2.1.32 ругается» — верить `sss2 -noplot -norun`, не доке.
`sss2 --version`/`--norun` в 2.1.32 не существует — только `-version`/`-norun`.
