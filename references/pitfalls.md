# Pitfalls 2.1.32 (собрано из провалов на HW-наборе)

1. Опечатка в имени карты молча склеивает её с предыдущей картой. Ошибка укажет не туда. Лечится `serpent-lint.py` + `-norun`.
2. Строки `sb`-спектра принадлежат `src` до следующей карты. Строка данных, начинающаяся с `mat/cell/set/det/ene/...`, разрезает карту.
3. `sg` на материале без decay-нуклидов → `emission rate 0`. Нейтроны: `Cm-250.03c` ок; фотоны: нужен `Cm-250`/`270600` (без суффикса) + `set declib`. Не менять метод на `sr` — чинить материал.
4. `de scale44` напрямую — ошибка входа. Сначала `ene e 4 scale44`, затем `de e`.
5. `dr -100 NAME` без `fun NAME ...` — ошибка входа.
6. Смешение атомных/массовых знаков в одном `mat` запрещено (плотность и фракции — один знак).
7. Мир не закрыт `outside` → ошибка/зависание геометрии. Держать `cell c_out 0 outside s_out`.
8. Абсолютные пути с чужой машины — переписать на относительные `xsdata/...` через `setup-env.sh`.
9. `photon_data/data.xsdata` — мусор-дубликат, не использовать. Правильный `pdatadir` = каталог с 11×`.dat`.
10. `jef3.dec` ≠ `sss_endfb7.dec` ≠ `s2v0_jeff311.dec`. Подмена даёт другую физику распада. Линтер предупреждает, какой файл реально указан.
11. `_det*.m` больше 20 МБ парсить только стримингом (`serpent-results.py` режет с пометкой `truncated`).
12. `set pop` и `set nps` взаимоисключают. В HW-наборе везде `set nps`.
13. Бачей `set nps` должно быть не меньше 20, иначе расчёт падает до транспорта
    (либо выключить генерацию констант через `set gcu -1`).
